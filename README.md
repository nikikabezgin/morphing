# Numeral Field

Одностраничная браузерная студия для генерации композиций из цифр.

## Запуск

Откройте index.html в современном браузере. Установка и подключение к серверу не нужны.

## Возможности

- Загрузка PNG, JPG, WebP и SVG; можно также перетащить файл на кнопку загрузки.
- Построение цифр по силуэту, потоку или контуру изображения.
- Настройка плотности, размера, морфинга, контраста, набора символов, цвета фона и чернил.
- Управление процентом цифр с подложкой, размером подложки и силой склеивания соседних форм.
- Анимированный предпросмотр, четыре варианта композиции и сброс настроек.
- Рисование и стирание формы прямо на холсте.
- Экспорт PNG размером 2560 × 1600 и SVG с векторными контурами цифр.

Изображение обрабатывается локально в браузере. Сервис не загружает его на сервер.

Для размещения на Vercel импортируйте репозиторий как обычный статический сайт.
Сборка и переменные окружения не нужны. Редактор предназначен для компьютеров;
на мобильных устройствах показывается сообщение об этом.
